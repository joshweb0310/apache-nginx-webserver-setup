Apache & Nginx Web Server Setup

Practical Linux Hosting‑Support Project

This project demonstrates how to install, configure, and troubleshoot both Apache and Nginx on Debian‑based Linux systems. It includes setup scripts, example configurations, permissions fixes, log analysis, and real-world hosting‑support troubleshooting scenarios.

## 🔧 Features
Apache installation & configuration
Nginx installation & configuration
Virtual host & server block examples
File permissions & ownership fixes
UFW firewall configuration
Log analysis for Apache & Nginx
Common error troubleshooting (403, 404, 500, DNS issues)
Step‑by‑step setup scripts

This project simulates real hosting‑support tasks, including web server setup, configuration, and troubleshooting. It is designed to demonstrate practical Linux skills for remote support roles and help desk positions involving web hosting environments.
